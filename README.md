# Movie Database (React + API)

React + TypeScript + Vite app using the [TMDB API](https://developer.themoviedb.org/docs) (v3).

## Run
1. Get a free API key (v3 auth) at https://www.themoviedb.org/settings/api
2. Copy `.env.example` to `.env` and paste your key into `VITE_TMDB_KEY`
3. Commands to run: `npm install` then `npm run dev`

This product uses the TMDB API but is not endorsed or certified by TMDB.
